# Косметичка — заметки для Claude

PWA для iPhone (Safari, экран «Домой») для учёта косметики Юли. Хостинг: GitHub Pages. Всё общение и интерфейс на русском.

## Правила

- **Без сборки и зависимостей**: чистые HTML/CSS/JS (ES-модули). Никаких npm, фреймворков и бэкенда. Данные только локально в IndexedDB (`js/db.js`).
- **Только относительные пути** (`./…`): сайт живёт в подпапке `/<repo>/` на GitHub Pages.
- **При любом изменении файлов** поднимай `CACHE` в `sw.js` и `APP_VERSION` в `js/config.js`. Новые файлы добавляй в `ASSETS` в `sw.js`.
- **Схема данных**: не ломай существующие записи, у Юли уже могут быть данные. Новые поля должны быть необязательными. Если нужна миграция, подними `DB_VERSION` в `db.js` и мигрируй в `onupgradeneeded`. Импорт старых JSON-копий должен продолжать работать.
- Категории (с иконкой и градиентом заглушки), статусы и варианты PAO настраиваются в `js/config.js`.
- **Дизайн** повторяет стиль Оранжереи (https://artem-161.github.io/oranzhereya/), который нравится Юле: Liquid Glass (класс `.glass`), живой фон из размытых пятен, засечный шрифт New York для заголовков, нижний док с «каплей» и круглой кнопкой «+», шторки снизу. Палитра — пудровая роза, все цвета в переменных в начале `css/styles.css`. Иконки — тонкие линейные SVG в `js/icons.js`, без эмодзи.
- iOS: шрифт в полях ввода не меньше 16px (иначе Safari зумит), учитывай `env(safe-area-inset-*)`, проверяй тёмную тему.
- Пользовательский текст всегда экранируй через `esc()` перед вставкой в `innerHTML`.

## Проверка

`python3 -m http.server 8080` в корне, открыть в браузере в размере iPhone (390×844). Иконки: `python3 tools/make_icons.py`.
