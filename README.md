# Косметичка 💗

Веб-приложение (PWA) для учёта косметики и уходовых средств. Работает на iPhone как обычное приложение с экрана «Домой». Все данные хранятся только на телефоне, в браузере (IndexedDB), без серверов и аккаунтов.

## Что уже умеет

- **Косметичка**: список средств с разбивкой «В деле / Запас / Закончились», фильтр по категориям, поиск.
- **Карточка средства**: фото (с камеры или из галереи, сжимается), название, бренд, категория, статус, дата вскрытия, срок после вскрытия (PAO, значок «12M» на баночке), «годен до», цена, оценка в звёздах, заметки.
- **Сроки**: средства, у которых истёк или скоро истекает срок. Срок считается как самая ранняя из двух дат: «годен до» и «дата вскрытия + PAO».
- **Хочу**: список желаний, примерная сумма и кнопка «Купила», которая переносит средство в запас.
- **Ещё**: статистика, резервная копия (сохранить или загрузить JSON-файл), удаление всех данных.
- Работает без интернета (service worker), поддерживает тёмную тему iOS.

## Как выложить на GitHub Pages

1. Создай репозиторий на GitHub, например `kosmetichka`.
2. Загрузи туда содержимое этой папки:
   ```bash
   git init
   git add .
   git commit -m "Косметичка: первая версия"
   git branch -M main
   git remote add origin https://github.com/<логин>/kosmetichka.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** → Save.
4. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/kosmetichka/`.

Все пути в проекте относительные, поэтому приложение работает из подпапки без настройки.

## Как установить на iPhone

1. Открыть ссылку **в Safari**.
2. Нажать «Поделиться» → **«На экран „Домой“»**.
3. Открывать с иконки. Данные приложения на экране «Домой» и данные в Safari хранятся **раздельно**, поэтому лучше сразу пользоваться только иконкой.

## Важно про данные

- Данные лежат только на этом телефоне. Если удалить иконку с экрана «Домой» или очистить данные сайтов в Safari, они пропадут.
- Поэтому иногда стоит делать **«Ещё → Сохранить копию данных»** и сохранять файл в «Файлы» или iCloud Drive. Из этого файла всё восстанавливается через «Загрузить из копии».

## Как обновлять

1. Поменять файлы.
2. **Поднять номер `CACHE` в `sw.js`** (например, `kosmetichka-v2`) и `APP_VERSION` в `js/config.js`.
3. Сделать `git push`. Телефон подтянет новую версию при следующем запуске с интернетом (иногда нужно закрыть приложение и открыть заново).

## Локальный запуск

```bash
python3 -m http.server 8080
```

Затем открыть http://localhost:8080. Service worker и IndexedDB работают на `localhost` и `https`, но не при открытии файла напрямую (`file://`).

## Структура

```
index.html            разметка: шапка, нижние вкладки, форма-шторка
css/styles.css        стили (светлая и тёмная тема, отступы под «чёлку» iPhone)
js/config.js          категории, статусы, варианты PAO, порог «скоро истекает»
js/db.js              обёртка над IndexedDB
js/app.js             состояние, экраны, форма, резервная копия
sw.js                 офлайн-кэш
manifest.webmanifest  описание PWA
icons/                иконки (генерируются через tools/make_icons.py)
```

## Модель данных (одно средство)

```js
{
  id: 'uuid',
  name: 'Крем для лица',
  brand: 'La Roche-Posay',
  category: 'face',          // id из CATEGORIES в config.js
  status: 'active',          // active | stock | finished | wish
  openedAt: '2026-11-01',    // дата вскрытия или null
  paoMonths: 12,             // срок после вскрытия, мес., или null
  expiresAt: '2027-06-01',   // «годен до» с упаковки или null
  price: 1890,               // или null
  rating: 4,                 // 0–5
  notes: '',
  photo: 'data:image/jpeg;base64,…',   // или отсутствует
  finishedAt: '2026-12-10',  // ставится автоматически при статусе «Закончилось»
  createdAt: '…', updatedAt: '…'
}
```
